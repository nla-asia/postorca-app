name: video-music
description: "Choose founder-supplied music and configure looping, fades and ducking."
---

Read video-create. Use music when requested, when the brief specifies a mood, or when there is no voiceover; otherwise speech and captions suffice. Prefer the founder's own music files. Use a named track when specified. List a supplied folder before selecting, then use read_file only for the chosen track. It saves audio as MP3 and returns a ref. For a long mix, set start_seconds and duration_seconds to read an excerpt a little longer than the video. Existing saved audio refs can be used directly. Without a supplied folder, list the first project folder. If no accessible folder is configured, explain what is missing.

Choose from known track metadata and names: calm instrumentals for focus or reflection, upbeat tracks for launches, warm slow tracks for personal moments. Prefer instrumental under speech. Metadata alone does not verify the sound. Do not generate replacement music when no supplied file is available; make a narrated video without music and explain the missing track. A music-only video needs the founder's track before proceeding.

Set start_seconds past a quiet intro if requested. Defaults are volume 0.15 with voiceover and duck enabled, or 0.6 for music-only. Speech lowers the track and pauses let it rise. Fades default to 0.5 seconds in and 1 second out; a beat can start without a fade and a slow ending can use 2–3 seconds. The track loops from its chosen start. Pace music-only shots around 2 seconds upbeat or 3 seconds calm while keeping overlays readable. Report the track source and selection reason; do not claim listening or accepted music balance without playback.
