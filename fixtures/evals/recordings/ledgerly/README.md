# Ledgerly screen recordings

Raw clips of the Ledgerly fixture app (`scripts/evals/ledgerly-fixture.mjs`), recorded
by the agent itself in a script-to-video eval (attempt `41f73509`, 2026-10-31): the Edge
window with its tabs, address bar and "started debugging" banner, as a founder's own
recordings would look. The editing evals start from these, so they test editing, not
recording.

- `1-dashboard.mp4` (4.5 s): the dashboard with the Outstanding, Paid and Overdue cards
  and the revenue chart.
- `2-new-invoice.mp4` (37.4 s): New invoice; Juniper Studio chosen, "Website redesign"
  at 2400, "+ Add line", "Copywriting" 4 at 150; the total reaches $3,000.00. Long,
  with slow typing.
- `3-mark-sent.mp4` (13.4 s): Save draft, the invoice page, Mark as sent; the badge
  turns Sent.
- `4-record-payment.mp4` (9.0 s): Record payment; the badge turns Paid.
