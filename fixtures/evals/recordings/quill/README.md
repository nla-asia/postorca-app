# Quill screen recordings

Raw window recordings of the Quill fixture app, a desktop notes app
(`scripts/evals/quill-fixture.mjs`), recorded by the agent itself in a script-to-video
eval (attempt `3b4d7a66`, 2026-10-31): the macOS window with its title bar, as a
founder's own recordings would look. No browser here, so the editing evals see a
different kind of app and frame from the Ledgerly set.

- `1-window.mp4` (5.6 s): the Quill window, the Weekly plan note open: sidebar,
  Markdown editor and live preview.
- `2-write.mp4` (19.6 s): in Weekly plan, "- Send the invites" typed at the end; it
  appears as a list item in the preview. Mostly waiting before the typing.
- `3-new-note.mp4` (14.9 s): File, New Note; the Untitled note becomes "Launch
  checklist".
- `4-search-pin.mp4` (15.9 s): "ideas" typed in Search notes, the list narrows to
  Chapter 3 ideas, and its star pins it.
- `5-dark-theme.mp4` (35.7 s): Quill, Settings; Theme switched to Dark and the window
  turns dark. Long, with a slow menu.
